# Run the incident workflow

Use the [project README](../README.md) to start Docker and retrieve a development account’s generated password.

1. Sign in as an employee and report a Payment Gateway issue. Set impact and urgency to critical and enter 300 affected users. Check the calculated priority and note the assigned technician.
2. Sign in as that technician. Acknowledge the ticket, record an investigation note and submit the resolution.
3. Sign back in as the reporter, verify the fix and close the ticket. Open its timeline to see the status changes.
4. Sign in as an administrator to inspect the audit log, review technician requests or export the incident report.
